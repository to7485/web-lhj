이름 인사 출력 프로그램
사용자가 화면에 이름을 입력하고 버튼을 누르면, JS의 fetch()를 이용하여
Springboot의 Controller로 이름을 전송한다.
Controller는 전달받은 이름을 Service로 전달하고, Service는 인사 문장을 생성하여 Controller로 반환한다.
Controller는 그 결과를 다시 브라우저에 반환한다.

프로젝트 : com.korea.test

브라우저에 나올 html ,js는 frontend라고 폴더 만들어서 작성하기

요청주소 GET /api/hello?name=xxx

controller : HelloController
- public String hello();

service : HelloService
- public String getHelloMessage(String name)
- 반환값은 안녕하세요, xxx님!

교육 과정 수강생 등록 및 조회 프로그램

HTML과 JavaScript를 사용하여 수강생 정보를 입력하고, Spring Boot 서버에 저장된 수강생 목록을 조회하는 프로그램을 작성합니다.

프론트엔드 파일은 Spring Boot 프로젝트 내부에 저장하지 않고 별도의 폴더에서 실행합니다.

프론트엔드
HTML + JavaScript
      ↓ fetch()
Spring Boot 서버
Controller → Service → ArrayList

데이터베이스는 사용하지 않으며, 입력받은 데이터는 Service 클래스의 ArrayList에 저장합니다.

프로그램 기능

프로그램은 다음 두 가지 기능을 제공합니다.

기능 1. 수강생 목록 조회
서버의 ArrayList에 저장된 모든 수강생을 조회하여 HTML 표에 출력합니다.

기능 2. 수강생 등록
사용자가 입력한 다음 정보를 서버로 전송합니다.

이름
과정명
이메일

서버는 전달받은 정보를 ArrayList에 저장하고 저장 결과를 반환합니다.

화면
student.html
입력 영역
이름 입력창 <input type="text" id="name">
과정명 선택창 <select id="course">
이메일 입력창 <input type="email" id="email">
수강생 등록 버튼 <button id="addBtn">수강생 등록</button>
목록 영역  
목록 조회 버튼 <button id="loadBtn">목록 조회</button>
수강생 목록 표 <tbody id="studentList"></tbody>
student.js

StudentController.java
- @RequestMapping("/api/students")

조회 기능
@GetMapping

ResponseDTO<StudentDTO>

등록 기능
@PostMapping

@RequestBody StudentDTO studentDTO

Service의 addStudent()를 호출한 뒤 저장된 수강생 정보를 반환합니다.
