Map 인터페이스
- Key와 Value가 한 쌍으로 하나의 데이터로 저장된다는것
- key는 중복될 수 없으나, value는 중복될 수 있음

HashMap : Map인터페이스를 구현한 대표적인 클래스
put(key, value); : 데이터의 삽입
ㄴ 없으면 추가, 있으면 value의 갱신이 일어남
get(key) : 해당 key와 연결된 value값을 반환
getOrDefault(key, default) : 해당 key의 value가 있으면 반환, 없으면 default값을 반환
remove(key) : map에 들어있는 데이터를 삭제
size() : 컬렉션의 크기를 반환
isEmpty() : 컬렉션이 비어있는지 검사
containskey(key) : 해당 key가 포함되어있는지 검사
containsValue(value) : 해당 value가 포함되어있는지 검사

keySet(); : map에 들어있는 모든 key만 추출하여 Set에 저장
values() : map에 들어있는 모든 value들만 가져오기
entrySet() : map에 들어있는 데이터를 하나씩 꺼내서 Set에 저장

향상된 for문, 람다식 -> 안써도 개발하는데 지장은 없음
ㄴ 효율적으로 코드를 작성해보고 싶다.


객체 지향 프로그래밍에서의 메서드 사용법
1. 클래스생성
2. 클래스안에 메서드를 작성한다.
3. 그 클래스의 객체를 생성한다.
4. 객체로부터 메서드를 호출한다.

함수형 프로그래밍
함수를 정의하면 객체 생성없이 호출하는게 가능하다.
다른파일에 함수를 정의했다면 import만 하면 사용할 수 있다.

람다식(lambda expression)장점
1. 간단하게 작성할 수 있다.
2. 핵심로직만 쓴다.

람다식을 구현하려면 함수형 인터페이스가 필요하다
- 추상 메서드가 딱 1개만 있는 인터페이스

람다식 기본문법
- 반환타입과 메서드명은 제거
(매개변수) -> {실행문}

매개변수가 1개일 때
- 소괄호는 생략이 가능하다
- 매개변수의 타입 생략이 가능하다

매개변수가 2개 이상일 때
- 타입을 생략하려면 전부 다 생략해야 한다.
- 소괄호 생략은 불가능하다.

반환할 값이 없고 명령이 1줄이면 중괄호 생략이 가능하다.

명령이 1줄이고 return과 중괄호를 같이 생략할 수 있다.

함수식을 변수에 담을 수 있다

변수를 통해서 함수를 호출한다.

매개변수에 함수를 전달한다.
반환값으로 함수를 반환한다.

2. ProductService 클래스 작성

ArrayList<Product>를 사용하여 상품 목록을 관리하시오.

다음 기능을 구현하시오.

1) 상품 등록
public void addProduct(Product product)
상품을 등록한다.
같은 code가 이미 존재하면 "이미 존재하는 상품 코드입니다."를 출력한다.

2) 전체 상품 조회
public void printAllProducts()

3) 상품 코드로 조회
public Product findByCode(String code)

4) 상품 정보 수정
public void updateProduct(String code, Function<Product, Product> updater)
상품을 찾아서 updater를 적용한다.
없으면 "상품이 존재하지 않습니다."를 출력한다.

5) 조건에 맞는 상품 조회
public void findProductsByCondition(Predicate<Product> predicate)

6) 조건에 맞는 상품 삭제
public void deleteProductsByCondition(Predicate<Product> predicate)
