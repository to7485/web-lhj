git (버전관리 프로그램)

버전을 만들어서 관리하는 과정
작업공간(작업) -> 스테이지(임시저장) -> 커밋(버전확정)

명령어로 관리하는 방법
1. 변경된 파일을 스테이지로 올리는법 : git add .
2. 버전을 확정하는 방법 : git commit -m "메시지"

프로그램으로 관리하는 방법
ㄴ githubdesktop

1. 작업공간에서 작업을 하면 자동으로 스테이지에 올라간다.
2. 메시지 적고
3. push origin 버튼을 눌러야 github로 올라감

java특징
운영체제(하드웨어와 소프트웨어의 중간 역할을 하는 프로그램)

1. 운영체제에 구애받지 않는다.
- 한 번만 작성하면 어디서든지 실행된다.

2. 객체지향 프로그래밍(OOP)
object-oriented programming

3. 자동 메모리 관리
메모리 -> 컴퓨터 RAM 부품
프로그램을 실행하면 메모리의 일정량을 차지한다.

프로그램 내부에서 사용되지 않는 것들을 자바가 알아서 제거

변수 : 데이터를 담는 상자다
프로그램에서 데이터를 저장하기 위해 메모리 공간에 이름을 부여한것

자료형 : 데이터의 재질과 크기
변수에 저장할 데이터의 종류와 크기를 정의하는 것

종류
정수형
byte		1byte
short		2byte
int		4byte
long		8byte

공부기록 남기기(꾸준히 기록 남기기)
그날 이해가 잘안됐던것, 해결이 안됐던것 -> 해결 과정

변수를 만드는 방법
1. 변수의 선언

자료형 변수명; -> 값이 들어있지 않은 상태

2. 변수에 값을 대입

변수명 = 값;

대입은 원하는 만큼 가능하다.
대입을 하면 이전의 값은 사라진다.

3. 변수의 초기화(initialize)

자료형 변수명 = 값;

초기화 후 대입이 가능하다.

기본자료형
정수형
문자형
실수형
논리형(boolean)

참조자료형
기본자료형 -> 값 자체를 들고 있다.
참조자료형 -> 값이 있는 주소값을 알고 있다.

형변환

자동형변환(묵시적형변환)
1. 작은 자료형 -> 큰 자료형
2. 문자형 데이터 -> 정수

강제형변환(명시적형변환)
2. 큰 자료형 -> 작은자료형
3. 정수 -> 문자
